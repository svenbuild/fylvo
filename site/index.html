Three commands on a Linux machine

You need Docker. The first start takes about a minute.

The first account you create becomes the admin. After that, registration is closed.

  1. mkdir ~/fylvo && cd ~/fylvo
  2. curl -fsSLO https://raw.githubusercontent.com/svenbuild/fylvo/main/docker-compose.yml
  3. docker compose up -d
  4. Open http://localhost:5212 and create your account.
